How it works

  1. Tag it

    Each item gets a signed NFC tag. The tag proves each tap is real, so a copied link is refused.

  2. Tap it

    Phone to tag, fingerprint, pick the action, submit. The app offers only the actions that make sense for that item right now.

  3. Report it

    Pull the custody history, use log, exceptions or certificates for any period, as PDF, CSV or JSON.

What your auditor gets

  • One custody history per item, from registration to destruction
  • A use log with one row per connection
  • An exceptions report: missing scans, expired hand-offs, broken seals, lost items
  • Certificates of sanitization and destruction, with photos and their SHA-256
  • Sealed, tagged bundles for drives going to a shredding vendor
  • A data export they can check themselves

A record that shows if anyone changes it

Events are chained together by hash, and each day's chain head is emailed to your admins. A changed or deleted record breaks the chain. Exports come with a short script that checks everything without CustodyTap, so your auditor doesn't have to take our word for it.

Questions

What is a transient cyber asset?

Under NERC CIP, a transient cyber asset is a laptop, test set or similar device that can carry executable code and is connected to a BES Cyber System's network for 30 consecutive days or less. Removable media are USB drives and other storage that can carry code. CIP-003-9 Attachment 1 Section 5 and CIP-010-4 R4 cover how both are managed.

Does CustodyTap need BES Cyber System Information (BCSI)?

No. Items are tracked by asset code and location code, and free-text fields remind people to keep system names and addresses out.

Is there an app to install?

No. Tapping a tag opens CustodyTap in the phone's browser. People confirm each action with their phone's fingerprint or face unlock, using a passkey.

What happens if a hand-off isn't accepted?

The item stays with the person who had it, and the missed hand-off appears on the exceptions report.

Can our auditor check the records without you?

Yes. Events are hash-chained, and every data export includes a short script that checks the chain and every file in the export without CustodyTap.
